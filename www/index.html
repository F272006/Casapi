Security & School Project Architecture

Transparency notes for teachers, project evaluators, and students:

Client-Side Password Security

Passwords are never stored in plaintext. They are hashed using the browser's crypto.subtle.digest('SHA-256') API before saving in localStorage.

Production Transition Path

A commercial release requires a Node.js/Python backend with salted bcrypt/Argon2 hashing, encrypted HTTPS cookies, JWT tokens, and PostgreSQL database.

Simulated Multi-User Environment

Multi-member voting and role assignments are simulated locally. Real multi-device collaboration requires WebSockets or real-time database sync.
